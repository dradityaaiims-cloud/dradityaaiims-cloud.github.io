# Medical Simulators (hub)

Static site, no build step. Open `index.html` through any static server, e.g. `npx vite .`.

- Add a simulator: one entry in `sims.js` plus a 16:10 screenshot in `assets/sims/`.
- Design language: paper, ink and oxblood, Libre Caslon Text + Karla (see `styles.css`).

Educational use only. Not a medical device.
